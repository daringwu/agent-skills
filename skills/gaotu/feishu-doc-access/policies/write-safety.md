# 写入安全与验证口径

## 身份与权限

- 只允许用户 OAuth 身份，所有真实调用显式使用 `--as user`。
- 不配置、不使用、也不自动回退到 bot/app 身份。
- scope 按当前任务增量申请。申请前说明用途；不得为避免后续授权而一次申请全部文档权限。

## 风险分级

在官方 `lark-cli` 风险等级之上采用以下加严规则：

- 单个普通创建、文末追加、目标唯一的精确局部修改可直接执行。
- 删除、全文覆盖、历史回滚、权限变更、owner 转移、移动以及任何批量操作均为高风险。
- 高风险操作先解析准确目标，展示计划或官方 dry-run；用户针对具体目标与参数明确确认后才能执行。

## 快照

全文覆盖、正文回滚或大范围删除前，必须把当前完整内容、文档标识和 revision 信息保存到当前工作区。
快照不得放入 Skill、机器配置目录或 Git。快照失败时不执行后续高风险写入。

## 回读与异常

- 每次写入后按影响范围重新读取并验证结果；结构变更后旧 block ID 一律视为失效。
- 如果返回超时、网络中断、部分成功或其他不确定结果，先查询当前状态，不得直接重试写入。
- 批量操作遇到首个失败立即停止，回读后分别报告已成功、失败、未执行项目，等待用户决定。
